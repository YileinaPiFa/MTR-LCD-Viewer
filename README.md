## 简介

MTR-LCD-Viewer 是一个用于预览、调试 MTR LCD 脚本资源的独立桌面工具。

无需启动 Minecraft，即可直接加载 MTR 资源包，解析 LCD 脚本并查看最终渲染效果。

项目通过模拟必要运行环境，使基于脚本驱动的 LCD 显示内容能够脱离游戏环境运行。
